# wide.79 三導航共用轉彎預調（測試）
高德車機版、高德一般版、Google NOO 接入共用轉彎預調。使用三者都能送出的有效轉彎／距離，車端沿用自己的轉彎速度及減速度設定。原生高德車機版匝道預調也保留。
- App 選擇對應導航並開啟原生智慧／預調速；comma 更新相容接收端後重啟，AutoNaviSpeedCtrlMode 大於 0。
- 共用預調使用 AutoTurnControlSpeedTurn（10–80）、AutoTurnControlTurnEnd、AutoNaviSpeedDecelRate。它是 App 授權的獨立減速候選，不啟用轉向／方向燈；AutoTurnControl 關閉時仍可預調。停用請關 App 預調或導航減速主開關。
- 已確認的左右轉／急轉可預調；直行、未知、抵達與僅出口提示不推測目標速度。高德一般版／Google 缺少主線限速時，不提供與高德車機版等效的匯入加速。
- 不改道路速限或巡航設定，較低的測速／彎道限制優先。通過轉彎後解除本項限制，由原有巡航處理。
- 原始引導和開關授權都限時，切換、停止、偏離、過期撤銷。沿用 wide.77 的投屏／日夜切換修正。
程式碼與建置測試在本分支；未經實車驗收，請小心使用。CI 產物為未簽章檔，不能取代正式下載 APK；正式 wide.77 保持不變。
