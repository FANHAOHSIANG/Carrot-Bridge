# wide.76｜高德車機版測速紅光修正

wide.75 只在 `Z3.k`（13005 獨立測速廣播）呼叫 Android 紅光更新。
高德也會透過 `Z3.l`（10001 導航更新）的 `CAMERA_DIST` / `CAMERA_SPEED`
傳送測速資料。這條資料已能送 HUD，卻沒有通知 Android 紅光，因此會出現
「高德與 HUD 都有測速距離，Android 四周沒有紅光」。實車這次使用哪種事件仍需紀錄確認。

現在兩個入口都在共同解析器 `Z3.A` 驗證資料、交給 `IG.r` 後，將同一筆
`T4` 測速樣本送到紅光。移除原本只掛在 `Z3.k` 的原始欄位呼叫。
無效或清除樣本會撤銷紅光，不把一般道路速限當成測速相機。

- 有效相機類型、相機速限及距離，500 公尺內觸發既有紅光漸層。
- 保留 2.6 秒過期機制與來源切換清除；不延長舊距離、不自行估算倒數。
- 不依賴神盾辨識開關或分區二，保留 wide.75 即時切換版面修正。
- 原簽章，versionCode 26110788，可覆蓋 wide.75。
- 這次修正僅 Android 提醒，HUD 和車輛控制輸出未修改。

## 重建與驗證

以簽章 wide.75 APK（SHA256 `b71cd675cc554a5101baca281c8b1f5c9f8d320f1e81b04ad626b032fb653dfe`）、
JDK 21、Android build-tools 35.0.0、Apktool 2.12.1：

```sh
python3 variants/wide76/build.py wide75.apk /path/to/android-15 /path/to/apktool.jar wide76-unsigned.apk
```

建置執行 16 項 JVM 邏輯檢查，並確認兩種廣播都進共同解析器、共用接線、切換清除與
動畫時鐘；重新組譯 DEX，確認 APK 只有兩個 DEX 與版本資訊改變。
私鑰不包含在儲存庫，簽署後需核對與舊 APK 相同憑證。

尚未完成實車顯示驗收。測試版請小心使用；需在有有效測速資料、500 公尺內確認
紅光，分區二開／關各確認一次，通過相機、資料停止或切換地圖後應撤銷。
