# wide.86｜高德資料觀察預覽

以 exact wide.85 APK 為基底，保留原投屏、導航與控車輸出。只修改本機使用者主動啟用的紀錄：
- type 2 道路路線封包擴大節點與字元預算（64,000 節點、1,500,000 字元）；其他事件維持原本限制。超限仍明確標記 truncated，不保證所有路線完整。
- type 14 車道引導、type 4 車道匹配、type 16 一般定位、type 2 路線觀察摘要；保留未知數值編碼，不解讀箭頭或把 0 當成有效定位。
- 既有三檔輪替由約 12 MB 提升至約 48 MB；紀錄起始版本修正為 wide.86。
- 座標系未知，control_input=false。資料只作離線分析，未接入 HUD 新圖示或任何控制；不自動開啟錄製。C4 既有獨立唯讀工具可另行匯出視覺資料，尚未整合時鐘／座標與即時傳輸。
- L4、高精度定位、原生車道中心線尚未接通。勿在行駛時操作。紀錄含位置，勿公開。

建置依賴精確 wide.85 SHA-256、Android SDK 35、JDK 21、Apktool 2.12.1。輸出未簽署，不能安裝；必須用原授權簽章私鑰重簽並核對憑證。公開簽章區塊不能重用於修改後 APK。
