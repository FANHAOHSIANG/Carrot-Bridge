# wide.89 — temporary PRE sender mitigation / 暫時停止 PRE 封包

Based on exact signed wide.88 (SHA-256 pinned). Until independently verified route/exit association and closed-loop tests are available, suppress both native `pre_adjust` and shared `pre_adjust_control` outgoing fields. Preserve the existing merged road-limit, SDI, traffic, guidance and diagnostic fields; do not generate a replacement speed. Existing user navigation features are otherwise unchanged by this targeted source patch. PRE functionality is intentionally unavailable, including correct exits. This is not the ROAD 36 fix, 20% protection, or linear speed control; no changes to C4. Existing C4 cached advice must expire. Build output is unsigned and not installable; no automatic release. Do not test on public roads as evidence of safety. Stop and verify operation while parked; keep problematic navigation-based speed control off.
