# Carrot Bridge 功能與地圖操作手冊

適用於目前發布的 **wide.70**，核對日 2026-11-15。[下載](../README.md#下載與需求) · [安裝](INSTALL_zh-TW.md) · [C4 分支比較](C4_BRANCHES_zh-TW.md)

## App 在整套系統的位置

App 在 Android 顯示地圖與其他 App，整理支援來源的導航資料，再透過區域網路送給 C4。C4 依自己的設定、模型與車型支援決定如何使用；App 不直接下達車輛 CAN 轉向或煞車命令。

| 功能層 | 看到什麼才算這層成功 | 還不能證明什麼 |
| --- | --- | --- |
| 投屏 | 目標 App 影格與觸控正常 | 已取得導航資料 |
| 來源 | 選定來源真的導航，診斷有新引導／路線 | C4 已接收 |
| Navi v2 傳輸 | 連線、訂閱及送出資料持續更新 | 車端已採用 |
| C4 接收 | 車端對應引導與紀錄更新，停止後撤銷 | 所有車型及道路的控制都已驗收 |
| 車端使用 | 設定允許、資料有效，候選被實際選用 | 能無人監督轉彎、煞停或駕駛 |

## 地圖與導航

### 高德車機版

**用途：** 使用車機介面，在高德內規劃路線，同時顯示其他 App 與車況。

1. 同機安裝高德車機版，完成定位與基本設定。
2. 選「分區二 ⋯ → 高德車機版」，完成投屏授權。
3. 在高德內選目的地並開始導航；該版本若有車機導航資料／廣播設定，依其介面開啟。
4. 查看「診斷與連線」中的選定來源、引導與距離，再核對 C4。

使用既有車機導航資料通道。轉彎、距離、測速或路線欄位以實際收到的資料為準；**看到導航畫面不代表完整路線或相機已送出**。版本與地區能力不同，未收到的欄位不推測補齊。

### 高德一般版

**用途：** 投屏手機版高德，透過 Link 將有效引導及選定路線交給 C4。

1. 選「分區二 ⋯ → 高德一般版」，依畫面完成 Link 授權。
2. 開始導航，查看診斷的 Link 授權、訂閱、有效引導及路線狀態。
3. 鍵盤若被擠住，用分區二選單切換「將鍵盤移至導航區／車機主畫面」。
4. 改選路線、停止或抵達後，核對舊資料撤銷；有目前轉彎不代表已有完整路線。

不要求使用者申請高德開發者 Key，使用高德 App 的 Link 認證／訂閱。路線以高德實際選定內容為準，不另請 Mapbox 規劃。手機版相機封包仍未確認；高德版本更新後仍須核對 Link 相容性。長路線配套差異見 [C4 比較](C4_BRANCHES_zh-TW.md)。

### Google 地圖（僅投屏）

**用途：** 使用官方 Google Maps App 的畫面、搜尋與語音。

選「分區二 ⋯ → Google 地圖（僅投屏）」，在 Google Maps 內操作。此模式不用設定 Carrot Bridge 的 Google SDK Key，也不從 Google Maps App 擷取路線／轉彎給 C4。若另開道路速限傳送，來源是 TDX／OSM，不能稱為 Google 回傳。

### Google 導航 NOO

**用途：** 使用 Carrot Bridge 內建 Google Navigation SDK，交付可用引導與路線給 C4。

1. 完成 [Google Cloud、Key 與套件限制](GOOGLE_SDK_zh-TW.md)。需 Google Play 服務、網路與精確定位，使用量可能計費。
2. 選「分區二 ⋯ → Google 導航 NOO」，在內建頁面搜尋、核對地址並開始導航。
3. 使用收藏、最近導航或地址入口快速選點；結束導航會清除引導並回到搜尋頁。
4. 分別核對 Google 模組、Navi v2 與 C4 接收狀態。

此選項用內建 SDK，不是從另一個 Google Maps App 擷取。名稱中的 NOO 表示導航整合用途，不保證車輛能自主通過路口。Google 速限、相機及號誌不在此版保證資料範圍。

### 神盾測速照相

**用途：** 在導航旁顯示神盾提醒，辨識成功時增加 App 四邊紅光。

1. 「分區一 ⋯ → 選擇投屏 App／空白畫面 → 神盾測速照相」。
2. 在神盾設定定位、提醒及語音；保持神盾投屏。
3. 到設定開啟「神盾紅光提醒、取樣與尺寸保護」。
4. 需至少 **757 × 384 像素**的辨識視窗及至少兩次一致取樣；辨識到 **500 公尺內**固定／移動測速時閃紅光，接近時加快、增亮。

視窗太小、資訊被遮、辨識失敗或資料過期時不能保證有紅光。關閉開關可解除這項尺寸保護。**辨識目前僅供 App 畫面與診斷，未接入 wide.70 的 C4 測速減速出站流程。** 神盾本身的語音及其他提醒依該 App 運作。

## 道路速限與 OSM

| 功能 | 操作 | 效果與限制 |
| --- | --- | --- |
| OSM 圓牌 | 「顯示 OSM 速限牌」 | 只控制畫面；無有效路段資料顯示「—」 |
| 圓牌位置 | 長按拖曳，點一下回預設位置 | 各地圖模式保存位置 |
| 道路速限出站 | 「傳送道路速限至 C4（TDX／OSM）」 | 優先同道路／方向 TDX，否則採已確認 OSM；未確認、衝突或過期時撤銷 |
| C4 採用道路速限 | 在 C4 核對設定與接收資料 | App 開關與 C4 是否採用分開；只接受符合接收協議的值 |

App 的 TDX／OSM 是**道路限速**；C4 的 `OsmCurveSpeedEnabled` 是**彎道速度預覽**，會在 C4 另外下載圖資。兩者不同開關、不同下載狀態；限速不是測速點清冊，也不代表已完整覆蓋全台每條道路。

## 畫面、快捷操作與常用地址

| 功能 | 操作 | 補充 |
| --- | --- | --- |
| 分區一 | 橫向右側，選神盾、其他已安裝 App 或靜謐時鐘 | 時鐘不是連線成功指示 |
| 分區二 | 橫向左側，選地圖來源 | 等待投屏顯示分區名，首個影格到達後收起 |
| 比例適配 | 拖分隔線或「版面與比例設定」，放開後等候適配 | 橫直向分別保存；目標 App 可能因尺寸變動重建畫面 |
| 返回／重啟 | 各區選單第一項「返回投屏 App」，或「重新開啟」 | 兩區可分別處理 |
| 面板收合 | 「⌄」收合，「⋯ → 展開面板」恢復 | 窄視窗集中到「⋯」 |
| 診斷／操作面板 | 分區一下方面板「切換」 | 車端快捷操作需連線與支援；停車設定 |
| 三組地址 | 「三個常用地址」；點選開啟、長按修改 | 不支援地址入口時複製，回地圖貼上確認 |
| 投屏管理 | 「投屏安裝與授權」查看服務、授權及連線 | 重開機後可能須重啟 Stellar／Shizuku |

## Amap2Tesla 瀏覽器投屏

此模式讓接收端瀏覽器觀看神盾，與 C4 導航傳輸分開。

1. 準備神盾及投屏授權，兩端使用可互通的 Wi-Fi／熱點。
2. 若瀏覽器投屏正在運作，先停止，再開「分區二 ⋯ → Amap2Tesla 僅投神盾」。
3. 啟動 Amap2Tesla，在接收端輸入 **App 顯示的完整網址與埠號**。
4. 要恢復本機分區一，先停止瀏覽器投屏，再關閉「Amap2Tesla 僅投神盾」。

車機瀏覽器與神盾虛擬螢幕相容性須實機確認。看到瀏覽器畫面不代表測速或導航資料已傳給 C4。

## 診斷與回報

1. 「即時診斷」查看車速、橫／縱向狀態、投屏服務、授權、來源與 Navi v2。
2. 「報告」分享當下狀態；需重現時先「開始記錄」，重現後「匯出報告與事件 ZIP」。
3. 註明 App／Android／地圖版本、C4 儲存庫／分支／提交及發生時間；公開 ZIP 前檢查位置、路線與連線位址。
4. App 正確而 C4 沒反應時，先查接收、來源及設定，不要只憑投屏成功就調高轉向或減速參數。
