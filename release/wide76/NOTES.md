# 高德車機版測速紅光修正

修正高德與 HUD 已有測速距離、Android 畫面四周卻不亮紅光的漏接：一般導航更新與獨立測速廣播現在共用已驗證的測速資料更新紅光。

- 保留 wide.75 關閉分區二不重建整個 Activity 的修正。
- 高德紅光不依賴神盾或分區二，500 公尺內且資料有效時觸發。
- 保留 2.6 秒過期撤銷、無效資料清除與切換地圖清除。
- 原簽章，可直接覆蓋 wide.75，無須先移除 App。
- 已通過 16 項 JVM 邏輯檢查、兩種入口接線檢查、DEX/APK 結構及原憑證驗證。

本版僅更新 Android 提醒，既有 HUD 與車端無須因本修正更新。實車紅光顯示仍待驗收；這是測試版，請小心使用。請確認測速 500 公尺內分區二開／關皆能顯示，通過相機或停止資料後能撤銷。
